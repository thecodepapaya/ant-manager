# Privacy Policy

Ant Manager is built with a **local-first, privacy-respecting philosophy**.

This document explains how data is handled.

---

## Data Collection

Ant Manager does **not** collect data automatically from external services.

Data is only processed when the user explicitly provides or enables it, such as:

- Selecting local git repositories
- Writing manual notes
- Importing transcript files
- Requesting summaries

---

## Data Storage

All data is stored **locally on the user’s machine**.

Typical storage includes:
- A local SQLite database
- User-selected directories for transcripts or configuration

No data is stored on Ant Manager-controlled servers.

---

## Network Usage

By default:
- Ant Manager does not communicate with any external servers.

Optional:
- Users may configure external LLM providers (e.g. OpenAI, Gemini).
- When enabled, **only the text required for the requested operation is sent**.
- External providers are governed by their own privacy policies.

Local LLM inference is supported and encouraged.

---

## Data Sharing

Ant Manager:
- Does not share data with third parties
- Does not include analytics or tracking
- Does not perform background uploads

Any export or copy operation is user-initiated.

---

## Security

- Ant Manager runs entirely on the local machine
- No remote access mechanisms are included
- Users are responsible for securing their device and backups

---

## User Responsibility

Users are responsible for:
- Ensuring imported transcripts comply with local consent laws
- Understanding the implications of enabling external AI providers
- Deciding what content to store or export

---

## Summary

Your data stays with you.

Ant Manager is designed to be understandable, inspectable, and predictable in how it handles information.
